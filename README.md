# 15분 Tech Talk 스터디

6주 동안 한 주제를 정해 **약 15분** 안에 발표하는 Tech Talk 스터디입니다.

## 진행 방식

- **발표 시간:** 주당 1인(또는 팀에서 정한 방식) 기준 약 15분
- **기간:** 6주
- **자료 정리:** 주차별 폴더(`week01` ~ `week06`)에 마크다운으로 간단히 남깁니다.

## 주차별 폴더

| 폴더 | 용도 |
|------|------|
| `week01` | 1주차: 앞으로 다룰 **발표 주제를 서로 공유**하고, 각자 계획을 md로 정리 |
| `week02` ~ `week06` | 해당 주차 발표·토론과 관련된 메모·링크·요약 정리 |

## 1주차에 할 일

1. 각자 **발표 예정 주제**를 정합니다.
2. `week01` 폴더에 **본인을 구분할 수 있는 파일명**의 `.md` 파일을 만듭니다.  
   예: `hong_gildong_topic.md`, `김철수_주제.md`
3. 파일에는 주제 제목, 왜 이 주제인지, 대략적인 범위 등을 **짧게** 적어 두면 됩니다.

## 이후 주차

- 발표 후 `week02` ~ `week06` 해당 주 폴더에 요약·참고 링크·질문 정리 등을 자유 형식으로 추가해도 됩니다.
- 팀에서 정한 규칙(발표 순서, 피드백 방식 등)이 있으면 이 README 아래에 이어서 적어 두면 좋습니다.

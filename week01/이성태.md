# 발표 예정 주제

## 1. 뤼튼 캐릭터챗(크랙)의 스트리밍 변천사
- **이름:** 이성태
- **한 줄 요약:** 크랙의 스트리밍이 SSE에서 WebSocket으로 변화해나가면서 발전한 내용과 그 과정에서 겪었던 어려움을 공유합니다.
- **다루고 싶은 범위:** SSE와 WebSocket의 차이, SSE를 사용하면서 겪었던 문제점, WebSocket으로 전환하면서 겪었던 문제점, Redis Sharded Pub/Sub

## 2. 대용량 이미지 업로드 파이프라인 구축기
- **이름:** 이성태
- **한 줄 요약:** 1600장의 이미지를 업로드하고 부적절한 이미지인지 검사하고 블러 처리하는 일련의 과정을 파이프라인으로 구축한 과정을 공유합니다.
- **다루고 싶은 범위:** AWS S3, S3 Trigger, SNS, SQS, lambda, cloudflare workers

## 3. 자동 구매는 처음입니다만
- **이름:** 이성태
- **한 줄 요약:** 결제 구현 경험이 없는 상태에서 자동 구매 기능을 구현하면서 겪었던 경험들과 사고의 흐름을 공유합니다.
  - 수많은 결제 기능들이 자동 구매를 트리거하게 하는 방법
  - 결제만 되고 재화는 충전되지 않는 문제(고아 결제)를 방지하는 방법
- **다루고 싶은 범위:** Saga 패턴, 메시지 큐
